# werkzeuge-oeffentlich — Workflows, die öffentliche Repos einbinden

Projekt: `../CLAUDE.md` (cloud-infra). Überblick: [README.md](README.md).

## Regeln

- **Alles hier ist öffentlich.** Hierher kommt nur, was ein öffentliches Repo einbinden muss und was
  ohne Schaden jeder lesen darf: keine Geheimnisse, keine Namen von Servern, Tresoren oder internen
  Abläufen über die Adresse von Cockpit live hinaus. Alles andere gehört nach `werkzeuge` (privat).
- **Jedes Repo hängt daran.** Eine Änderung wirkt sofort in allen Repos, die `@main` einbinden;
  erst im Vorhaben-Branch, zusammengeführt wird mit dem Nutzer.
- Actions nur mit fester Commit-SHA und Versionskommentar.
